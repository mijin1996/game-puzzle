# 프로토타입

## 핵심 플레이 루프

피스가 떨어진다 → 옮기고 돌려서 쌓는다 → 줄을 지운다 → 줄이 쌓이면 새 방향이 열린다 → 판을 돌려가며 여러 방향을 동시에 관리한다 → 막히면 게임오버.

## 프로토타입 범위 (v0.1)

- STANDARD 모드 하나 (1변 → 4변 해금)
- 키보드·게임패드 조작 (조작표는 architecture.md 1.5)
- 단색 사각형 스프라이트 블록, 기본 HUD (점수·레벨·줄 수)
- 판 회전 연출 (0.15초 Z축 회전)
- 사운드, 메뉴, 저장은 제외

## 검증할 것

1. 1단계(Top만)가 일반 스태커처럼 자연스럽게 느껴지는가
2. 2번째 방향이 열릴 때 플레이어가 회전을 바로 이해하는가 (안내 UI 필요 정도)
3. **겹치는 중앙 칸의 간섭**이 재미인가 — 한 레인을 정리할 때 이웃 레인 블록이 같이 밀리는 것이 재미인지 짜증인지
4. 판 20 · 레인 폭 10(레인 깊이 10)이 적절한가 (레인 폭 8 / 10 / 12 비교)
5. 해금 조건 10 / 25 / 45줄이 적절한가
6. 회전 중 입력 버퍼가 답답함을 없애는가

## 실행 방법

- `Assets/Scenes/SampleScene`을 열고 Play. 씬에 아무것도 추가하지 않아도 `GameBootstrap`이 자동으로 만들어진다.
- 값을 바꾸려면 Project 창에서 `Create > Quadrop > Game Config`로 `Assets/Resources/GameConfig.asset`을 만든다.
- 테스트: `Window > General > Test Runner > EditMode > Run All`.
